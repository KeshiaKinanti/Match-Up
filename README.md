## General Information  
*Match-Up!* is a memory game where players flip dessert plates to find matching pairs. Designed with accessibility and playful aesthetics in mind, the game blends visual storytelling with cognitive challenge.

- **Problem it solves:** Encourages memory recall and attention through interactive gameplay.  
- **Purpose:** To explore game logic, sprite design, and user experience in MakeCode Arcade.  
- **Why I built it:** As part of my final-year Communication degree at UTS, I wanted to create a game that’s both technically sound and emotionally engaging.

---

## Technologies Used  
- **MakeCode Arcade** – visual block and JavaScript-based game development  
- **JavaScript (MakeCode variant)** – for custom logic and sprite control  
- **Pixel Art Editor** – for designing custom sprites and backgrounds

---

## Features  
- Flip-to-reveal memory matching mechanic  
- Countdown timer for added difficulty  
- Highlight cursor with blinking animation for accessibility  
- Custom sprite design with picnic-themed desserts  
- Responsive feedback and win screen

## Setup  
No installation required — playable directly in browser via MakeCode Arcade.  
To edit or remix the game:  
1. Go to [MakeCode Arcade](https://arcade.makecode.com/)  
2. Import the project using the shared link  
3. Modify sprites, logic, or UI as needed

---

## Usage  
- Use arrow keys to navigate the grid.  
- Press **A** to flip a plate and reveal the dessert.  
- Match two identical desserts to score a pair.  
- Complete all matches before the timer runs out!
